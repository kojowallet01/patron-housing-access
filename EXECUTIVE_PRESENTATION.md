## 🎬 How It Works (User Workflows)

### **1. Visitor Registration & Entry (30 seconds)**

**First-Time Visitors:**
1. Scan entrance QR code with smartphone
2. Complete one-time registration (name, phone, purpose)
3. Receive instant digital access token (4-digit code + QR)
4. Show token to security for verification
5. Granted access immediately

**Returning Visitors:**
1. Scan entrance QR code
2. Enter phone number only
3. Receive new daily access token
4. Show token to security
5. Granted access with visit history displayed

### **2. Security Verification (10 seconds)**
1. Security officer scans visitor's token or enters 4-digit code
2. System instantly validates credentials
3. Displays visitor information and any security flags
4. Officer grants or denies access based on verification
5. All actions logged automatically

### **3. Administrative Oversight (Real-Time)**
1. Admins access centralized dashboard
2. View live visitor counts, peak hours, and trends
3. Generate compliance reports with one click
4. Manage user permissions and security flags
5. Export data for analysis or auditing

## 🔐 Security & Access Control

### **Three-Tier Role System:**

#### **1. Super Administrator**
- **Access Level:** Organization-wide (all 5 campuses)
- **Capabilities:** Full system control, password management, cross-campus reporting
- **Use Case:** Executive oversight and system administration
- **Authentication:** Master password with session management

#### **2. Campus Administrator**
- **Access Level:** Single campus scope
- **Capabilities:** Visitor management, reporting, data export, security flagging
- **Use Case:** Day-to-day campus operations management
- **Authentication:** Campus-specific credentials with role-based permissions

#### **3. Security Staff**
- **Access Level:** Verification-only access for assigned campus
- **Capabilities:** Token validation and visitor information display
- **Use Case:** Entrance checkpoint verification
- **Authentication:** Limited-scope credentials for security operations

### **Token Security:**
- 4-digit codes with daily expiration (prevents reuse)
- Collision detection ensures unique codes per day
- QR code generation for touchless scanning
- Verification audit trail with timestamps
- Session-based authentication (24-hour validity)
