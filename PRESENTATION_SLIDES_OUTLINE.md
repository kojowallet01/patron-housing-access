### **SLIDE 5: How It Works - Visitor Flow**
**3 Simple Steps:**

1. **SCAN** entrance QR code with phone
   - Opens registration page automatically
   
2. **REGISTER** once (or just enter phone if returning)
   - Takes 20-30 seconds
   
3. **RECEIVE** digital access token (4-digit code + QR)
   - Show to security → Walk in!

### **SLIDE 6: How It Works - Security Verification**
**Instant Token Verification:**

1. Visitor shows 4-digit code or QR on phone
2. Security officer scans or types code
3. System validates instantly: ✅ Green (Allow) or ❌ Red (Deny)
4. Displays visitor info and any security alerts
5. All activity logged automatically

**Average verification time:** 10 seconds
